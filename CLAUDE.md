# CLAUDE.md

See [AGENTS.md](AGENTS.md). One file, so the two cannot drift.

The part most often got wrong: **open with the bottom line, then a table or
bullets, in plain language.** Short. Say what a thing is before naming it —
register and symbol names are evidence for a table cell, not the sentence
that carries the meaning. Detail goes in the commit message, not the chat
reply; the user asks when they want more.
